# hackatonTeam14
# О программе
Автоматическая система обработки корпоративной почты. Читает письма из папки `inbox`, классифицирует их по категориям и раскладывает в соответствующие папки.
Система:
- сканирует папку `inbox` с письмами 
- извлекает из каждого письма тему, отправителя и текст
- автоматически определяет категорию письма (спам, срочное, финансы, техподдержка, другое)
- перемещает письмо в соответствующую папку внутри `treated/`
- ведёт логирование и выводит статистику обработки

# Установка и запуск
1) Откройте терминал. 
2) Для начала склонируйте репозиторий на компьютер: введите git clone https://github.com/mo0isss/hackatonTeam14.git, затем нажмите Enter. Дождитесь завершения клонирования. 
3) Перейдите в папку проекта: введите cd hackatonTeam14 и нажмите Enter.
4) Теперь создайте папку для писем: введите mkdir inbox и нажмите Enter или создайте папку вручную. Положите ваши письма в папку inbox через Finder или Проводник, просто перетащив файлы в папку. 
5) Установите pytest для запуска тестов: введите pip install pytest и нажмите Enter. Если pip не работает, попробуйте python3 -m pip install pytest.
6) Дайте права на выполнение bash-скрипта (только для Mac и Linux): введите chmod +x src/bash-script.sh и нажмите Enter. На Windows этот шаг можно пропустить.
7) Запустите программу. Введите bash src/bash-script.sh и нажмите Enter
8) После запуска программа сама прочитает все письма из папки inbox, определит категорию каждого письма и переместит их в папку treated. Внутри treated появятся папки с названиями категорий: documents, spam, hr и тд. В каждой такой папке будут лежать соответствующие письма.

# Дополнительно
Если вы хотите проверить, что всё работает правильно, запустите тесты: введите pytest tests/ -v и нажмите Enter. Если все тесты прошли успешно, вы увидите надпись "5 passed" и зелёные галочки. Если какой-то тест упал, проверьте, что вы находитесь в правильной папке и что все файлы на месте.


# Сруктура проекта
hackatonTeam14/
|- inbox/              # папка с входящими письмами (добавляется пользователем)
|- treated/            # папка с обработанными письмами (создаётся автоматически при вызове баш-скрипта)
|- src/
|   |-identifier/     # модуль классификации
|   |-logsAbndStatisctics #модуль логов и статистики
│   |- mover/          # модуль перемещения писем
│   |- parser/         # модуль парсинга писем
│   |-bash-script      # bash-скрипт для запуска
|- tests/              # тесты
|   |-identifierTest  # тесты для классификации 
|   |-logsAndStatisticsTest # тесты логов и статистики 
|   |-moverTest # тесты перемещения писем 
|   |-parserTest # тесты парсинга писем
|- main.py             # главный файл, слияющий все модули
|- conftest.py #без него не работают тесты у одного члена команды (парсинг)
|- README.md #информационный файл
