# hackatonTeam14
## О программе
Автоматическая система обработки корпоративной почты. Читает письма из папки `inbox`, классифицирует их по категориям и раскладывает в соответствующие папки.
Система:
- сканирует папку `inbox` с письмами 
- извлекает из каждого письма тему, отправителя и текст
- автоматически определяет категорию письма (спам, срочное, финансы, техподдержка, другое)
- перемещает письмо в соответствующую папку внутри `treated/`
- ведёт логирование и выводит статистику обработки

## Установка и запуск
1) Откройте терминал. 
2) Для начала склонируйте репозиторий на компьютер: введите git clone ```bash https://github.com/mo0isss/hackatonTeam14.git ```, затем нажмите Enter. Дождитесь завершения клонирования. 
3) Перейдите в папку проекта: введите cd hackatonTeam14 и нажмите Enter.
4) Теперь создайте папку для писем: введите ``` bash mkdir inbox``` и нажмите Enter или создайте папку вручную. Положите ваши письма в папку inbox через Finder или Проводник, просто перетащив файлы в папку. 
5) Установите pytest для запуска тестов: введите ``` bash pip install pytest``` и нажмите Enter. Если pip не работает, попробуйте ``` bash python3 -m pip install pytest```.
6) Установите pymorphy3 для корректного запуска программы: введите ``` bash pip install pymorphy3```. 
7) Дайте права на выполнение bash-скрипта (только для Mac и Linux): введите ``` bash chmod +x src/bash-script.sh``` и нажмите Enter. На Windows этот шаг можно пропустить.
8) Запустите программу. Введите ``` bash bash src/bash-script.sh``` и нажмите Enter
9) После запуска программа сама прочитает все письма из папки inbox, определит категорию каждого письма и переместит их в папку treated. Внутри treated появятся папки с названиями категорий: documents, spam, hr и тд. В каждой такой папке будут лежать соответствующие письма.

### Дополнительно
Если вы хотите проверить, что всё работает правильно, запустите тесты: введите ``` bash pytest tests/ -v``` и нажмите Enter. Если все тесты прошли успешно, вы увидите надпись "N passed" и зелёные галочки. Если какой-то тест упал, проверьте, что вы находитесь в правильной папке и что все файлы на месте.
